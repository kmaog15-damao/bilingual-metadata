# 中文文献双语元数据

让中文论文在参考文献表中同时显示英文和中文信息，方便准备中文期刊投稿材料。

插件会为中文文献创建一条关联的英文记录，再根据你选择的 Zotero 引用样式生成双语版本。英文信息存放在独立记录里，不会改掉中文题名、作者或期刊名。

## 安装

适用于 Zotero 10.0–10.x。

1. 从项目的 [Releases 页面](https://github.com/kmaog15-damao/bilingual-metadata/releases/latest) 下载最新的 `.xpi` 文件。
2. 打开 Zotero，选择「工具 → 插件」，点击齿轮图标，选择「从文件安装插件…」。
3. 选中刚下载的 `.xpi` 文件，安装后重启 Zotero。

## 使用前建议

建议先安装并配置好「茉莉花」和「LLM-for-Zotero」两个插件，再使用本插件处理中文论文。茉莉花可协助整理中文文献信息；LLM-for-Zotero 中的 MinerU 功能配置完成后，可以先用它解析论文，等解析结束后，再回到 Zotero 多选条目执行本插件的操作。

这两个插件不是本插件的强制依赖；不使用它们时，仍可手动填写英文信息，或使用本插件能找到的网页、快照等来源。它们也不会替你完成双语 CSL 的创建。

如果要让本插件查找 MinerU 解析结果，还需另外打开「设置 → 双语引用」，填写包含 MinerU 输出 Markdown 文件（例如 `full.md`）的本地目录并保存。这里填写的是本插件搜索解析文件的位置；即使 LLM-for-Zotero 中已经配置了 MinerU，本插件也需要知道到哪里查找这些文件。没有使用 MinerU 时可以留空。

## 怎么使用

### 1. 为中文文献准备英文记录

等茉莉花、LLM-for-Zotero 的 MinerU 等工具处理完文献后，在 Zotero 文库中选中中文论文，右击选择「创建英文引用条目…」。核对英文题名、作者和期刊名，再确认创建。创建的英文记录会和中文原记录关联。

插件提供的英文信息只是候选内容，可能缺失或有误。请对照论文、期刊网页等来源检查后再保存。作者可按“姓 || 名”填写，多位作者用分号隔开。

### 2. 创建双语引用样式

打开 Zotero「设置 → 双语引用」，点击「创建双语 CSL…」，选择 Zotero 中已有的引用样式，或导入期刊提供的 `.csl` 文件。按期刊要求选择英文在前或中文在前，查看预览后保存并安装。

原有样式会保留。生成的新样式会以“关联双语”标识，方便之后在 Zotero 和 Word 中选择。

### 3. 在 Word 中引用

打开 Word 的 Zotero 文档首选项，选择刚安装的“关联双语”样式，然后刷新文献表。选择中文原记录进行双语引用；如果是纯英文投稿，则选择英文记录，并使用对应的普通英文样式。

## 使用前请留意

- 英文题名、作者和期刊名需要你核对，插件不会保证自动找到或翻译出正确内容。
- 并非所有期刊样式都能自动转换。若当前样式结构不受支持，插件会提示；请检查生成预览是否符合期刊要求。
- “关联双语”样式需要插件启用，才能在引用中文原记录时读取对应的英文记录。
- 不要删除英文记录与中文原记录之间的关联；否则该中文文献会按原中文信息显示。
